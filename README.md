# Cheatsheet on command lines
![command lines](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRpDsLO5ji4RdZcDK3kiyrkIS-0I5dNdBwX6aTyWSScMXcfY4qxyVYqnoLX&s=10)
## Command lines that are going to be explained here:
- mkdir < name >
- touch < file >
- cd < folder >
- cd ..
- clear
- rmdir < name >
- rm < file >
## Commands
1. `mkdir < name >`
_ _ _
Command **mkdir** is used to create *a new folder*. In between symbols **< and >**, we put a *name* of the folder.
_ _ _
2. `cd < name >`
_ _ _ 
This command we use to *enter* the folder.
_ _ _
3. `cd ..`
_ _ _
This command we use to *exit* the folder
_ _ _
4. `rmdir`
_ _ _
This command is used to *remove* empty folder
_ _ _
5. `touch`
_ _ _
This command is used to *create* a **file**
_ _ _ 
6. `rm < file>`
_ _ _
This command is used to *delete* a file.
_ _ _ 
7. `clear`
_ _ _
This command is used to **clear** everything
_ _ _ 
**Important notes: file cannot be entered!**
### Example
```    
    mkdir folder#1
    cd folder#1
    touch file.txt
    mkdir folder#2
    cd folder#2
    cd ..
    rmdir < folder#2 >
    rm file.txt
    rmdir < folder#1 >
```
